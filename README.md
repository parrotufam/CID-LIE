# CID-LIE Dataset

---

CID-LIE (Controlled Illumination Dataset for Low-Light Image Enhancement) is a dataset designed to evaluate low-light image enhancement methods under controlled illumination conditions. Unlike traditional benchmarks, it explicitly considers variations in light intensity and number of light sources, enabling a more detailed analysis of model robustness and generalization.

The dataset provides paired low-light and full-illumination reference images captured in a controlled setup, allowing both full-reference (PSNR, SSIM, LPIPS, DISTS) and no-reference (NIQE, BRISQUE) evaluations.

CID-LIE is intended to serve as a more realistic and structured benchmark for studying illumination-aware performance in low-light image enhancement methods.
